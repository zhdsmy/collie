## 上游新增功能

本版主要增加配对与隐私保护、离线阅读，以及 Files 和单手操作功能。

| 功能 | 现在的行为与使用影响 |
| --- | --- |
| 读取必须配对 | 所有 `/api/*` 读取和操作都要求有效令牌，仅健康检查与领取配对码公开；未配对的 Tailnet 浏览器和脚本需要先配对。注册表损坏返回 503，不退化成无鉴权。 |
| 本机 CLI 凭证 | bridge 每次启动生成本机只读凭证；只接受直接本机请求，不接受代理头。Files 的设备读取权限仍需配对令牌。doctor、history 等本机命令沿用原用法。 |
| 配对有效期 | `collie pair --expires 30d` 可限制令牌期限，默认永久；devices 支持设置或清除期限。过期设备同名重新配对会同时撤销旧令牌。并发领取同一码只成功一次。 |
| 密钥遮蔽 | 默认在 bridge 遮蔽已知前缀 API key、JWT、PEM 私钥、Bearer 和 password 等赋值；覆盖镜像、Chat、History、工具文本、Files、Changes、通知与 Crew 转发。相同宽度圆点保持布局。普通密码和任意十六进制不保证命中。 |
| 遮蔽状态 | Settings → System 展示只读状态；首次遮蔽有可关闭说明，发送包含遮蔽文本时有提示。只有服务器 `COLLIE_REDACT=off` 可关闭；手机不能关闭。 |
| 解绑清理 | 解绑、撤销和过期清除令牌、草稿、推送订阅、会话缓存及 IndexedDB，保留显示偏好和应用壳。清理可在下次启动续做；可手动清除保存副本。撤销前说明清理范围并二次确认。 |
| 统一设备存储 | herd 与最近面板文本迁入 IndexedDB，默认 24 小时、单面板 256 KiB、总计 10 MiB；无 IndexedDB 时退回内存。 |
| 离线阅读 | 保存最近 Chat，可选关闭、1 天、7 天，默认 1 天；断线保留并注明副本时间。冷启动可展示保存的 herd。密码提示清除该面板保存内容。 |
| 离线操作保护 | 保存副本不能发送、确认、取消或启动操作；仍可编辑草稿。恢复连接不会自动补发，也没有重试队列。 |
| 左手布局 | Settings → Appearance → Hand 镜像操作带位置，发送、附件和手机 Files 返回键移到左侧；图标与文字顺序、键盘 tab 顺序保持可读。 |
| 文件路径链接 | Chat、工具卡片和终端中的路径经 bridge 批量验证存在且在仓库内后可点击，支持行号。只用于本机 lead，Crew 成员路径保持文字。 |
| 分支新智能体 | 菜单可在所选分支建立 worktree 并启动另一个智能体或 shell；请求有幂等回执，网络重试不重复建 worktree。仅 Herdr lead 支持。 |
| 图片预览 | Files 按内容识别 PNG/JPEG/GIF/WebP/AVIF，最大 16 MiB；显示透明棋盘、尺寸和类型。SVG 提供 Source/Preview，以不能运行脚本的图片方式显示。Markdown 支持仓库内相对图片。 |
| 分支信息 | 面板和 Files 显示当前分支或 detached 提交；读取仓库小文件，不启动 git，不阻塞快照。非法 ref 和 bidi 控制字符被拒绝。 |
| Claude Send now | 等待发送的消息可用 Ctrl+Enter 交给当前轮次，修复后台通知挤掉排队消息的问题。仅能正确发送 Ctrl+Enter 的 Herdr 显示，离线或只读时不可用。 |
| 五种语言 | 新增俄语、意大利语、法语、巴西葡萄牙语、土耳其语，合计十二种；俄语复数和按需 Cyrillic 字体补齐。 |

## 界面与兼容性修复

采用上游布局和连接修复，并继续保留本地紧凑操作带。

| 范围 | 完整变更 |
| --- | --- |
| 连接提示 | 连接、鉴权、更新提示浮在顶栏下，不推挤页面；可关闭当前断线提示，顶栏图标仍显示状态。滚动区为提示留出首行空间。离线草稿说明只在首次键入后浮现，可关闭。 |
| 重连 | 单次轮询最多约 6 秒；网络无响应后按 0.5/1/2/4 秒短退避重试。刚唤醒的第一次无响应先重试一次，避免闪红。实际错误和权限拒绝保持常规节奏。WebKit 超时与主动取消分别处理。 |
| 离线面板 | 缺少在线快照不再被判定为已关闭；无保存文本时明确说明无副本。返回 Chat 时带上实际持有窗口，避免空白和错误 304。 |
| Files 导航 | 返回到实际来源（面板、diff、Markdown 文件）；面包屑回到已有层级，不重复堆栈。面板在子目录时从该目录打开。 |
| Files 布局 | 紧凑页头、路径独立一行、中间路径省略；Diff/Source/Preview 使用图标和无障碍名称；保留已读 diff，切回来立即展示。Previous/Next 到边界时弱化。手机底部补充返回键，键盘打开时隐藏。 |
| Dashboard | 顶部统一为状态摘要、needs-you 开关、工作区与排序选择；窄屏按优先级缩短状态文案。隐藏工作区可从列表恢复，取消长按隐藏。 |
| 点击区域 | tab 和 pane 的点击范围限制在各自行内，避免覆盖下面第一行文件链接。 |
| 图片发送 | 校验发送中的图片路径时暂不展示“终端草稿”提示，完成后仍有草稿才恢复。见 [#370](https://github.com/AltanS/collie/issues/370)。 |
| OMP 18.8 | slash palette 替代状态行时仍识别输入框，先读回命令再提交；补宽屏和 48 列捕获。见 [#373](https://github.com/AltanS/collie/issues/373)。 |
| Antigravity | 自定义 statusLine 最多向上搜索八行；单选项问题框的 footer/编号规则阻止被误判为输入框。见 [#374](https://github.com/AltanS/collie/issues/374)。 |
| Herdr 0.9.3 | 仓库根目录从 worktree.list 获取并按工作区缓存，适配不再携带根目录的工作区记录。 |
| zellij 0.44+ | 从 pane listing 获取实际 cwd，启用 Files、Changes、分支与同目录启动；旧版没有此信息时保持不可用。 |
| 语言一致性 | 修复德、西、日、韩、简中、繁中丢失的 `{mux}` 插值和韩语状态标签；加入全语言键、占位符和破折号校验。俄文字号匹配 Aldrich/Space Grotesk。 |

## 安全、文档与工具链

这些上游变更同时影响脚本、浏览器缓存和维护约定。

- typed 字符、空格和 Tab 按正文规则脱敏后写审计日志，命名按键仍可读；旧日志不会被追溯重写。
- API 图片使用私有缓存策略；响应增加 Permissions-Policy、CSP 限制和 HTTPS HSTS。配对每来源每分钟最多十次尝试。
- Crew lead 使用自己的遮蔽规则处理旧成员文本；遮蔽版本进入 ETag，无法安全处理的响应不以缓存结果直接透传。PEM 扫描改为线性复杂度，并校验修改规则时必须更新 MASK_VERSION。
- 配对脚本和 Crew probe 支持设备 token 或本机只读凭证；文件读取、配对竞争与分支名边界同步加固。
- Playground 按章节分页、各组有子页、预览 frame 对齐；测试调整异步配置读取时序、Blob 跨平台断言、FIFO 及鉴权后的 Crew/E2E 假数据。
- 上游打包元数据跟进 1.17.2（[#369](https://github.com/AltanS/collie/pull/369)），保留对应安装器和平台测试变化；本地版本按 Collie 后缀发布。
- README、架构、设计、接口契约、部署/安全/配对/Files/离线等文档及 ADR 0086–0090 更新。安全说明新增：iOS 应用切换器截图可能保留面板内容，网页无法保证消除系统快照。
- 回退到 1.18.0 以前会忽略 token 的过期字段；必须立即阻断某设备时应撤销设备，不能只依赖到期时间。

## 与本地定制的合并

没有整项删除或替换已选定的下游功能；以下重叠部分组合使用。

| 原有实现 | 上游合并方式 | 用户可见结果 |
| --- | --- | --- |
| 紧凑操作带、8px 渐隐与自定义字体 | 叠加左手布局及上游连接浮层 | 保持紧凑外观，可切左手使用。 |
| Codex、Claude、Hermes 定制卡片 | 共用上游在线状态，下游 Picker 补同样的离线锁 | 保留模型、Resume、Agents、Settings、历史等；保存副本无法误操作。 |
| 刚恢复的 Codex 问答、Plan、review | 保留选择、笔记、分题确认和 Submit all；异步问题保持原生 | 不撤回最近实测恢复的功能。 |
| 原文尾部匹配与原生输入 | 合并上游遮蔽匹配，保留尾段匹配与直接输入 | 遮蔽开启后仍能确认发送；离线停止发按键。 |
| 最近模型记录 | 接入上游统一 wipe，包含未加载会话和旧全局键 | 解绑不遗留会话模型信息；密码提示不清除该偏好列表。 |
| 原有七语言的定制字符串 | 五种新语言同步补齐 152 个键，旧语言保留正确占位符 | 新语言不会漏掉本地卡片和设置文案。 |
| Plan Markdown 内容恢复 | 合并 Markdown 图片 alt 文本规则 | 带图片的计划文本可以正确匹配。 |
| 软折行末段、PWA 高度、通知约定、16px agent 图标 | 保留已有实现 | 延续此前选定的显示与通知行为。 |
| canary 独立传输 | 发送前调用真实客户端读取路径确认在线 | 不人为绕过离线保护；仍支持用旧 checkout 的 reader 对比。 |

继续不启用 GitHub Actions，不创建 GitHub Release；发布 main 和注解标签，使用既有本地证书签名，只重启 Collie。
