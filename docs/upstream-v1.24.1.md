## 发送与输入

- **启动期间避免消息落入 shell。** 记录 Collie 启动的智能体；Herdr 还读取实际前台进程，覆盖脚本和手动启动。未出现目标输入框时拒绝发送，不把“写入 shell”误报为发送成功。其他 multiplexer 无法读取同等进程信息时，保护范围较小；启动最初一瞬仍有原生识别边界。
- 输入框已绘制但尚未接收按键时停止继续写入；清理仅属于 Collie 的 `⌁` 探针，绝不删除混有用户文本的探针。连续两次发送不再留下 `⌁⌁`；启动期间的消息保持原顺序，后一个不继承前一个的等待状态。
- 智能体由启动状态转为可识别状态，不再被误判为 pane 已替换，已输入文本和等待消息可继续提交。真实会话更换仍中止发送。
- **Claude 运行中排队恢复可靠确认。** 长提示、编号列表、勾选列表与多段回显不再误判成菜单；原生排队后的屏幕证据确认发送，减少 held 或“可能到达”的误报。
- **OMP 长文本一次发送。** 输入框只显示最后若干行时按可见尾部验证，并在回执中记录验证范围；Discard 按实际已知文本长度删除。Replace 无法确认完整草稿长度时提前拒绝，避免删半条或删到错误位置。
- 已有真实草稿的发送直接拒绝，保留 Append／Replace／Cancel；对疑似陈旧屏幕先验证输入框是否接收探针，再读一次。无法确认时提示重绘，不执行危险清空。慢速版本读取完成后才开始发送的时间预算。
- Herdr 桌面滚动到历史时读取 live screen，短期共享前台状态查询；窗口刚调整尺寸的发送允许稳定后继续，避免误判框消失。
- 等待消息按“运行中／有界面打开／已有草稿”更新真实原因；空闲且输入框腾空后及时放行，不因错过运行状态而卡住。

## OMP 识别、命令和卡片

- 覆盖 18.6.1、18.12.6 的状态栏扩展、简短或 ASCII 状态行、最多十二行连续下置 widget、`field` 和 `claude` 输入框；长命令列表与 widget 并存仍能发送。
- 支持 `@file`、`#issue`、末尾 `#`、`:emoji`、完整和未完成文件路径的原生补全 popup，忽略清空输入框后残留的 popup 行；命令中的 `@file` 仍可能被 Enter 选中时给出具体拒绝原因。
- 绝对路径、`~/`、`./`、`@/` 不再当成斜杠命令，路径状命令不会误执行 `/loop`。不提交指向其他命令的 fuzzy 补全；迟到的补全界面也必须复验。
- 命令弹出慢速全屏页面可确认已提交；列表超过三行、ASCII 符号、带状态栏或短对话的 `/plan` 不再误报失败。允许有界、保持顺序的正文移出验证区，新增或乱序正文仍阻止发送。
- 引用权限对话、框线的正文不再被当作真实 modal；换行草稿回读不额外插空格；两行草稿读不到时明确说明读到了什么。Clear 在 `claude` 输入框形态不再误报打开对话。
- `/skill:name args` 的 chip 及两代图片 chip 可验证；拒绝用户直接发送会被 OMP 替换成历史粘贴正文的 chip 标签。`->`、`=>` 等原生保留前缀发送前拒绝并解释，清除使用原生 clear key。
- 运行中拒绝 `/exit`、`/quit`、`/q`、`/restart`，避免延迟到结束后突然退出；支持停止 OMP 正在执行的 shell 命令。
- 问答卡片支持 plan-mode、选项预览、自定义文本；审批卡片支持 goal、subagent 和三选项 bash 审批。Deny 发送 Escape，避免行选择变化导致误批准。识别 rewind picker 为未卡片化 modal，等待用户关闭，不把消息写进列表。
- 上述新增卡片样本登记到既有 adaptation catalog；仅记录上游真实 ANSI 回放证据，未将本机安装版本标记为已通过原生交互认证。

## 队列、历史、状态和界面

- **队列消息不再无声消失。** OMP Stop 放回输入框的排队或引导消息，在 Chat 保留“回到输入框”卡片，可 Submit／Discard；多条返回内容合并为同一张可验证卡片。只有 journal 接收、明确返回草稿或明确未知时才结束对应状态；无法定位时说明未知，不虚报送达。
- pi、OMP、Codex、OpenCode 从日志及本机模型列表读取上下文；未知模型窗口不猜测。Claude、pi、OMP、OpenCode 有实际费用时显示会话美元费用，Codex 无来源则不显示。
- 上游把模型、上下文和限额显示为一行。本地保留紧凑状态栏中的上下文和限额，模型标签只补充尚未显示的字段与费用，避免重复圆点；屏幕已命名模型且无额外数据时不重复命名。
- OMP 和 Gentle Shell 的后台子任务计入 Agents 数量和列表；仅 Chat 已加载时可统计，没有独立 transcript 的任务不提供虚假的打开入口，结束后移除，失败则标记失败。
- Steer 提示改为输入框的短占位文案，十二种语言均缩短，不再为提示增减一行。默认 Steer 时不显示“长按发送来引导”的提示。
- iPad 安装版 PWA 增加覆盖全宽的顶部颜色条以缓解系统顶端模糊；不移动正文，无需重新安装。真机效果本轮未验证。

## 诊断、隐私、配置和工程

- `collie doctor` 展示 instance、stateDir、每个已支持智能体的程序路径、版本及 profile 判定；JSON 同样包含这些字段。读取的是 pane 实际运行程序时，发送回执记录对应 binary/version；未安装或无法读取版本会区分报告。
- 连续三次属于 Collie 的发送失败，可出现“报告问题”卡片。pane 菜单和 Settings／System 也可打开同一报告页，设置可关闭提示。默认报告不含消息正文或屏幕；用户可选择加入已保留文本、经过模式遮蔽的末四十行屏幕，并在打开 GitHub 表单或复制前检查全部内容。报告 API 仅供已配对设备读取，服务端不自动外发，不持有 GitHub token；crew 成员暂不显示自动失败卡片。模式遮蔽不等于保证清除所有敏感内容。
- 新增 `from-app` issue 表单；更新 Configure、Troubleshooting、Security、Commands、multiplexer 文档与 HERDR API 说明，以及采样出处、审批/问答笔记、十二种语言文案。
- Codex hooks TOML 扫描支持以四或五个引号结束的合法多行字符串，仍拒绝六个及以上的歧义形式。
- 新增 ADR 0122（队列卡片至 journal 接收）、0123（用户选择报告）、0124（profile 完成后计时），同步输入框、权限、费用、steer 等既有 ADR。
- 补充启动窗口、pane binary、队列、journal receipt、问题报告和缓存测试，以及 Claude／OMP 原生 browser rig 场景、占位提示和 PWA top-edge 浏览器检查；Windows 跳过预算从 157 调至 162。依照 fork 规则不恢复 GitHub workflows，本轮不发布或演练 Windows 二进制。
- 更新 AUR、Nix 发布元数据；Workbox precache 上限统一到上游 3 MiB 常量，修复应用主 chunk 略超 2 MiB 导致构建失败。本地已有重复配置已合并，未新增生产依赖。
