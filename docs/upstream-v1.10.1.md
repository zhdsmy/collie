## 上游完整变更

### Dashboard

状态汇总中的图标、数字和名称保持为一个整体。窄屏容不下所有状态时整项换行，避免单个计数被拆成两行；同一组件用于工作区计数。

更新 README 使用的 Dashboard 截图。没有新增导航、设置项或状态类型。

### Claude 输入、状态栏与命令补全

1. 输入框改为按自身边框定位：先确认底边、提示符和顶边，再分类下方内容为状态栏、命令补全或未知内容。原来的 8 行限制只控制状态栏提取，不再决定是否允许发送；未知尾部仍显示在原生正文中。
2. 支持窄窗格中以 `…` 开头的截断命令名，包括截断落在 `-`、`_`、`:` 的情况，以及带括号别名的命令。修复已经输入文本但因未识别补全列表而不按 Enter、需要再次发送的问题。
3. 对状态栏自身绘制的非编号 `❯` 行和带标题横线作受限兼容，不将它们直接当成新的输入框或菜单。仍要求它们位于已确认的状态栏范围内，拒绝第二个输入框的形状。
4. 拒绝把真正的菜单当成普通输入框：检查已知选择框、编号选项、按键说明和未知尾部中的对话框标记。后台 Agent 界面虽然有自己的输入框，也不能接受普通对话发送；历史搜索等占用键盘的界面同样受到保护。
5. 超过 8 行的状态栏可保留原生显示而不阻断正常输入；不能可靠分类的尾部不再被隐藏。`@` 文件补全仍不新增专用卡片。

### Agent 边界、测试与文档

- Antigravity 的异类屏幕识别增加 `tell Claude`，避免将部分 Claude 选择框识别为 Antigravity。保留下游既有的 Codex Plan footer 排除规则。
- 新增 64 份 Claude Code 2.1.274 捕获样本，覆盖 40–200 列、长草稿、粘贴占位符、补全、各种选择框、工作中状态和自定义状态栏；新增逐样本预期表与输入框测试，补充发送保护测试及绑定区域数据。
- 样本测试明确保留已知边界：以 `❯` 开头的草稿续行、shell 模式、编号状态行仍可能被保守拒绝；后台 Agent 自有输入框的拒绝是预期保护。两份没有任何 Claude 特征、会被 Antigravity 误认的 Edit 样本未纳入共享语料，不能将本次测试视为已解决该识别边界。
- 新增 ADR 0048，更新 ADR 0004、ADR 索引、CLAUDE.md 和 fixture 来源说明，记录从“跨过尾部寻找输入框”改为“先识别完整边框再分类尾部”的原因、保护与局限。
- 发布提交统一上游三个版本文件和 CHANGELOG。没有依赖更新、后端协议变更、安装迁移、构建工具链调整或 Workflow 变更。
