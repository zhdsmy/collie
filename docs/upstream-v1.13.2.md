# 上游 v1.13.2 合并报告

从下游 `v1.13.1+collie.12` 跟进上游 `v1.13.2`，目标版本为
`v1.13.2+collie.1`。逐项核对了[发布说明](https://github.com/AltanS/collie/releases/tag/v1.13.2)、
上游 `CHANGELOG.md` 和 [v1.13.1...v1.13.2 标签差异](https://github.com/AltanS/collie/compare/v1.13.1...v1.13.2)。
标签间改动 78 个文件；没有新增产品页面、后端接口或配置迁移。

## 上游变化

### Codex 0.156.1

- [状态行与输入框修复](https://github.com/AltanS/collie/commit/100bf7e3)识别新版本的静音前景色分隔符和右侧警告提示，恢复默认窗格的输入框、换行草稿及正常发送；仍要求真实的输入区绘制证据，避免把正文当作输入框。
- 同一提交识别改写后的文件夹信任提示、文件编辑审批、仅两个选项的命令审批，以及窄窗格里折行的审批选项。文件编辑审批使用屏幕印出的 `y`、`Esc`；持久授权选项不变成一键批准按钮。上游仍让更新提示、`/model`、`/permissions` 走未知对话框的 Esc 退路。

### Claude 2.1.283

- [对话框修复](https://github.com/AltanS/collie/commit/71b28a1e)及[复核补丁](https://github.com/AltanS/collie/commit/c71085e7)按问题和选项识别权限请求，包括隐藏 `Tab to amend` 提示、没有该提示的网页抓取请求，以及窄窗格中折行的拒绝选项。编辑说明文字时暂停其他答案按钮，避免数字写进说明框。
- 问答中的 `Type something` 是文本字段，不再把已输入内容误当作选项；焦点在字段上时不代按其他选项，多选或多步问答退回 Esc 卡片。跨行问题和选项标签会完整显示，不带多余的边框竖线。
- 粘贴的分隔线或 `❯` 开头文本仍属于 Claude 草稿，不再让发送误判为没有输入框。计划文件放在自定义 `CLAUDE_CONFIG_DIR` 时，计划审批仍可识别。
- `/mcp`、`/hooks`、`/memory`、`/rewind`、`/effort`、`/status`、`/usage`、`/export`、`/login` 的新版弹层边界和按键提示可识别。Claude 尚未画出首帧或已经退出而 Herdr 状态稍晚更新时，shell 提示符不再短暂显示 Esc 卡片。

### 文档、测试与打包

- ADR 0048 补充“输入框内缩进的规则线和 `❯` 是草稿”的判定，ADR 0053 增加显示未知对话框卡片所需的正面弹层证据；同步更新开发说明和真实终端捕获样本。新增的 Codex、Claude 样本及单测覆盖正例、折行与误识别反例。
- [E2E 修复](https://github.com/AltanS/collie/commit/4283ca65)让没有取得交换服务器锁的跳过用例不再清除别的测试正在使用的延迟、失败和限速指令。
- [打包元数据](https://github.com/AltanS/collie/commit/0a2e4bf7)将 AUR 和 Nix 的下载来源及校验和从 1.13.0 更新到 1.13.1；这是本次标签内的上游状态，未在下游改写为未经上游发布的下载地址。上游正式版本文件升至 1.13.2，下游发布时使用自己的 `+collie.1` 后缀。

## 下游合并决定

- **用上游新版信任卡片替换下游原生显示。** 之前的 Codex 文件夹信任提示只显示终端原文，现在 0.156.1 的 `Trust this folder?` 提供“信任并继续”和“退出”按钮；按当前指针移动后以 Enter 确认。旧版 0.149 信任文案仍原样显示，不恢复数字快捷键适配。
- 继续保留 Codex 当前 `resume`、`/model`、`/permissions`、statusline 选择器卡片和发送保护；上游的 Codex 0.156 状态行识别与这些能力合用。
- 继续保留命令审批卡片的完整环境、原因、命令与持久授权说明；接入上游两选项、折行和文件编辑审批识别。上游只显示拒绝行的卡片边界由本地完整上下文取代，用户可直接看见审批对象。
- Claude 旧版 Settings 嵌套导航仍原生显示；新版 `/usage` 在带 `▔` 边界和独立 Esc 提示时显示卡片。保留仓库现有的紧凑同底操作带、实体底部导航和不恢复 GitHub 发布工作流的策略。

除文件夹信任提示外，本次没有替代其他下游实现。

## 合并验证

- Claude 与共享适配器测试 1,970 项通过；Codex、resume、未知对话框和受保护动作的定向测试 1,941 项通过。两组有共享测试，数字不可相加。
- 根目录与 Web 类型检查、lint、版本一致性、AUR 与打包刷新脚本检查通过。正式标签构建和本机运行回读在发布后完成。
