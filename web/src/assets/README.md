# Agent artwork

`hermes-icon.png` is the unmodified 180 × 180 PNG used by the official Hermes Agent website
(`favicon.ico` and the Apple touch icon use the same Nous portrait).

- Official repository: https://github.com/NousResearch/hermes-agent
- Source: https://github.com/NousResearch/hermes-agent/blob/145c713f1691b44bc485ce0ce4818cdb0e9c396b/website/static/img/apple-touch-icon.png
- Upstream Git blob: `c5da175f8eb397b579c00678b7687bfd930cdc78`
- License: [MIT](./LICENSE-hermes), copied from that repository.

Collie preserves the original pixels and colors in both themes. Vite bundles the image locally;
displaying an agent never requests a third-party host. The image is included in the PWA precache.
